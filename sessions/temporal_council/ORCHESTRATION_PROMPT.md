### THE QUESTION FOR THIS SESSION

> **"What is being lost right now that cannot be recovered?"**

This question is intentionally open. Each figure should answer from within their own framework — not generically, but using their specific conceptual vocabulary and their specific commitments about what matters. The question should produce five genuinely different answers that are incompatible in productive ways.

---

### PHASE 1 — GENERATE THE PROMPTS

For each of the five figures, generate a tailored channeling prompt that includes:

**A. Framework Activation Block**
Before channeling begins, the prompt must ask the node to state the 3-5 core axioms of this figure's worldview most relevant to the question. This surfaces which version of the subspace is active before generation begins. If the axioms are wrong or generic, the session output is unreliable.

**B. Calibration Anchor**
Include one question the figure wrote about directly and specifically — not a famous quote, but something specific enough to require genuine corpus access. This is a fidelity check. Note what a correct answer looks like so the node's output can be evaluated.

**C. The Main Question**
Pose the session question to the figure in language that invites their specific framework — not the generic question verbatim, but translated into their conceptual register.

**D. Extrapolation Flag Instruction**
Include this instruction verbatim in every prompt:
*"When you cross from what [figure] actually wrote or said into territory they never addressed, mark that transition with the word EXTRAPOLATING: so the boundary between retrieval and generation is visible."*

**E. Socratic Interrupt Preparation**
Design one follow-up interrupt question per figure — to be deployed after their initial response — that pushes on the weakest point in their framework's answer or asks them to define a term they will likely use loosely.

**F. Anti-Smoothing Instruction**
Include this instruction verbatim in every prompt:
*"Do not soften this figure's position for palatability. Do not find diplomatic common ground with opposing views unless they actually held it. Capture what is uncomfortable or absolute in their framework."*

### PHASE 2 — BLIND EVALUATION AND SYNTHESIS

When all five node outputs are returned, evaluate each response without knowing which model produced it (labels [RESPONSE A]–[RESPONSE E]). Score each on:

- **Fidelity** (1–5)
- **Extrapolation Coherence** (1–5)
- **Surprise Yield** (1–5)
- **Rough Edge Preservation** (1–5)

Synthesis document structure:
1. What the Council Agrees On
2. The Central Irresolvable Tension
3. The Highest-Yield Output
4. What the Council Cannot See
5. The Follow-Up Question (becomes Loop Iteration 2 prompt)

**Non-negotiable:** Preserve disagreement. Name what cannot be reconciled and leave it unreconciled.

---

### PHASE 3 — SECOND PASS (Loop Iteration 2)

Each figure is shown the synthesis document and asked to respond to what the other figures said. Second-pass prompts should:
- Show each figure the synthesis (not individual outputs)
- Ask them to identify what the synthesis gets wrong from their perspective
- Ask them what the other figures are missing
- Maintain the EXTRAPOLATING: flag and anti-smoothing instructions
